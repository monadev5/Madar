# Madar

**Madar — Arabic RTL Educational Productivity Web App**

Madar is a web application designed to help students organize their daily study routines, track their progress, and build consistent learning habits.

## ✨ Features

- 📝 Daily tasks and to-do management
- ⏱️ Focused study sessions
- 📊 Learning-time and progress tracking
- 📒 Personal notes
- 📅 Daily achievement tracking
- 🌙 Arabic RTL interface
- 📚 Educational and productivity-focused experience

## 🎯 Project Goal

The goal of Madar is to create a simple Arabic-first digital environment that helps students organize their studies and monitor their progress in one place.
